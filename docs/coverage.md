# What the registry holds, book by book

Date: 2026-11-23 · counts only, recounted from `registry/*.json` and `registry/queue.json`.

One record per rulebook entry (a spell, a feat, an option, a class or subclass feature, a species or one of its traits, a
background, an item, one feature of a monster's stat block). This page is **not** a measure of what works: a verdict says
what an entry needs, not that it is done, and only the last column counts rules the module registers.

Books published in or after 2024, and Tasha's and Xanathar's, were read entry by entry by reader agents
(`docs/coverage-5e24.md` has the detail of the 2024-era ones). For the other older books only the entries that have an item
in a local source were read: without the item a reader cannot tell whether "the item's data is enough", so the rest — nearly
all of them monster features of books with no official Foundry module — stay without a verdict until an item exists (a dump
of imported monsters, for instance). Their "official item" column is 0 by lack of a module, and DDB Importer has local dumps
for spells and items only. How far one reading can be trusted: `docs/reader-agreement.md`.

## Not in the registry

- *Ravenloft: The Horrors Within*, *Arcana Unleashed*, *World of Warcraft*: an official module with a local dump, but not
  in the dataset the texts are fingerprinted from.
- *Humblewood Tales* (`HAT-TG`): its book code is refused by the tools (a hyphen).
- Magic item variants built from a template, item groups, and items whose text comes from a shared template.
